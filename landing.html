Déploiement Vercel

Déployer sur votre domaine
en 5 étapes

Passez de GitHub Pages à Vercel avec votre sous-domaine officiel budgetsmart.misswaxbeautycare.com

1

Créer un compte Vercel

Allez sur vercel.com → cliquez "Sign Up" → connectez-vous avec GitHub (même compte que votre repo). C'est gratuit.

2

Importer votre projet GitHub

Sur Vercel → "Add New Project" → Cherchez budgetsmart-app-v2 → Cliquez "Import" → "Deploy". Vercel détecte automatiquement que c'est un site statique.

3

Créer le fichier vercel.json

Dans votre repo GitHub, créez un fichier vercel.json avec ce contenu :

{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }], "headers": [{ "source": "/(.*)", "headers": [ { "key": "Cache-Control", "value": "public, max-age=3600" }, { "key": "X-Frame-Options", "value": "DENY" } ] }] }
4

Ajouter votre sous-domaine

Sur Vercel → votre projet → Settings → Domains → Ajoutez budgetsmart.misswaxbeautycare.com. Vercel vous donne 2 enregistrements DNS à ajouter.

5

Configurer chez votre registrar

Allez sur le panneau DNS de votre domaine misswaxbeautycare.com → Ajoutez un enregistrement CNAME :

Nom : budgetsmart Type : CNAME Valeur : cname.vercel-dns.com TTL : 3600

✅ Votre app sera disponible sur budgetsmart.misswaxbeautycare.com en moins de 24h !
